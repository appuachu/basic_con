      🎥 Live Monitoring Workflow
      
    
      What a sysadmin actually does to watch for attacks in real time
      

    
      
        
      
            
      1
      
            
      
                
      Open terminal & tail a log
      
                
      Watch auth.log in real time — every login attempt shows up as it happens
      
                sudo tail -f /var/log/auth.log
            
      
        
      
        
      
            
      2
      
            
      
                
      Filter out noise with grep
      
                
      Only see what matters — filter for failures, errors, or a specific IP
      
                sudo tail -f /var/log/auth.log | grep --line-buffered 'Failed\|Invalid'
            
      
        
      
        
      
            
      3
      
            
      
                
      Watch for bursts
      
                
      Many failures in a short window = attack in progress
      
                sudo journalctl -u ssh -f | grep --line-buffered 'Failed'
            
      
        
      
        
      
            
      4
      
            
      
                
      Identify the source
      
                
      Grab the attacking IP and rank by attempt count
      
                sudo grep 'Failed password' /var/log/auth.log | awk '{print $(NF-3)}' | sort | uniq -c | sort -rn | head
            
      
        
      
        
      
            
      5
      
            
      
                
      Block the attacker
      
                
      Use UFW to instantly drop traffic from the attacker
      
                sudo ufw deny from 203.0.113.5
            
      
        
      
        
      
            
      6
      
            
      
                
      Document & escalate
      
                
      Save log excerpts for the incident report
      
                sudo grep '203.0.113.5' /var/log/auth.log > /tmp/incident-$(date +%F).log
            
      
        
      
    
      

      



      
    
      🛠️ Must-Install Log Analysis Tools
      
    
      These tools amplify your logging — from centralizing to alerting
      

    
      
        
      
            sudo apt install fail2ban
            
      Fail2ban — Watches logs and auto-bans IPs that fail too many times. Essential for SSH.
      
        
      
        
      
            sudo apt install rsyslog
            
      rsyslog — Central syslog daemon. Forward logs to a remote server.
      
        
      
        
      
            sudo apt install logwatch
            
      logwatch — Daily email summary of important log events.
      
        
      
        
      
            sudo apt install auditd
            
      auditd — Kernel-level auditing — tracks every syscall, file access.
      
        
      
        
      
            sudo apt install lnav
            
      lnav — Terminal log viewer with filtering, syntax highlighting, SQL queries.
      
        
      
        
      
            sudo apt install goaccess
            
      goaccess — Real-time web log analyzer (HTML dashboard).
      
        
      
        
      
            sudo apt install multitail
            
      multitail — Watch multiple logs in a single terminal.
      
        
      
        
      
            sudo apt install tripwire
            
      tripwire — File integrity monitoring — detects changes to critical files.
