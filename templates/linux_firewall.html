🎬 Real-World Scenario: Block an Attacker

    
An SSH brute force attack is hitting your server right now — here's what to do


    

        

            
1

            

                
You notice attack in auth.log

                sudo grep 'Failed password' /var/log/auth.log | tail -20
            

        

        

            
2

            

                
Find the attacker IP

                sudo grep 'Failed password' /var/log/auth.log | awk '{print $(NF-3)}' | sort | uniq -c | sort -rn | head -5
            

        

        

            
3

            

                
Block with UFW

                sudo ufw deny from 203.0.113.5
            

        

        

            
4

            

                
Verify the block

                sudo ufw status | grep 203.0.113.5
            

        

        

            
5

            

                
Watch next attempt get blocked (live)

                sudo tail -f /var/log/ufw.log | grep '203.0.113.5'
