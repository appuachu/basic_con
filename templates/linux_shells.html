🎯 What Is a Shell?

A shell is a command-line interpreter that reads your commands, expands variables, executes programs, and returns their output. It's the interface between YOU and the Linux kernel. Every login gives you a shell (usually bash on Linux, zsh on macOS).

📝 Same Task, Different Shells

Here's how each shell handles a simple task — printing numbers 1 to 3

sh 
#!/bin/sh
i=1
while [ $i -le 3 ]; do
  echo $i
  i=$((i+1))
done
bash 
#!/bin/bash
for i in {1..3}; do
  echo $i
done
zsh 
#!/bin/zsh
for i in {1..3}; do
  echo $i
done
fish 
#!/usr/bin/fish
for i in (seq 1 3)
    echo $i
end
