💻 Common chmod Commands

chmod 755 file.sh

Owner: rwx, Others: r-x — typical executable

chmod 644 config.txt

Owner: rw-, Others: r-- — typical data file

chmod 600 ~/.ssh/id_rsa

Private SSH key — ONLY owner can read

chmod +x script.sh

Add execute for everyone

chmod u+s /usr/bin/prog

Add SUID bit — runs as owner (root)

chmod +t /shared_dir

Sticky bit — only owner can delete files
